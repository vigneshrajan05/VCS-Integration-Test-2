## Failures

All 3 failures share the same root cause:

| Assertion | Message |
|---|---|
| Validate `api_info` has `version` | `expected { status: 'healthy' } to have property 'version'` |

**Root cause:** The upstream NEA backend returns `api_info: { status: 'healthy' }` — the `version` field is absent from the live response, despite being marked `required` in the OpenAPI spec. This is a **spec vs backend mismatch**, not a proxy or gateway issue.

**Recommendation:** Either update the OpenAPI spec to make `version` optional, or raise with the backend team to align the response with the spec.
